# Come utilizzare le skill dello Studio Legale Introcaso con ChatGPT

## 1. Cosa sono

Le skill sono istruzioni operative specializzate, conservate in questo repository. Non sono programmi autonomi e GitHub non le installa automaticamente in ChatGPT. Servono a far applicare un metodo stabile alle attività dello Studio.

## 2. Il modo più semplice: richiamarle in chat

Con GitHub collegato a ChatGPT, apri una nuova conversazione e scrivi, ad esempio:

> Per questa attività consulta nel repository introcasoantonello/studio-legale-Introcaso la skill più pertinente, leggi il file SKILL.md prima di iniziare e applicane le istruzioni. Se non puoi accedere al repository, dimmelo senza fingere di averlo consultato.

Poi descrivi il lavoro e allega i documenti necessari.

Puoi anche indicare direttamente il modulo:
- Atti civili: `skills/redazione-atti-civili/SKILL.md`
- Ricerca giurisprudenziale: `skills/ricerca-giurisprudenziale/SKILL.md`
- Analisi fascicolo: `skills/analisi-fascicoli/SKILL.md`
- TAR e diritto amministrativo: `skills/diritto-amministrativo-tar/SKILL.md`
- Contratti e stragiudiziale: `skills/contratti-consulenza-stragiudiziale/SKILL.md`
- Termini processuali: `skills/scadenziario-processuale/SKILL.md`
- Compensi e spese: `skills/calcolo-compensi-spese/SKILL.md`
- Modelli dello Studio: `skills/archivio-modelli-studio/SKILL.md`
- Controllo qualità: `skills/controllo-qualita-atti/SKILL.md`
- Metodo generale: `skills/diritto-italiano/SKILL.md`

## 3. Prompt pronto da copiare

> Lavora come assistente giuridico dello Studio Legale Introcaso. Prima di iniziare, individua e consulta nel repository GitHub introcasoantonello/studio-legale-Introcaso le skill pertinenti all'incarico. Leggi integralmente i relativi file SKILL.md e applicane il metodo. Seleziona anche il modello dello Studio eventualmente allegato o disponibile, senza modificarne arbitrariamente struttura e formulazioni. Distingui sempre fatti documentati, allegazioni, inferenze e questioni da verificare. Non inventare norme, sentenze, massime, date, importi o dati processuali. Per ogni precedente giurisprudenziale indica gli estremi e verifica che esista e che sia pertinente; se non puoi verificarlo, dichiaralo. Non affermare di aver consultato Italgiure, DeJure o altri archivi se non vi hai effettivamente avuto accesso. Redigi in italiano giuridico, con stile discorsivo e professionale, rispettando le mie indicazioni di formattazione. Prima di consegnare, esegui il controllo qualità fattuale, normativo, processuale e redazionale. Non effettuare depositi, notifiche o invii senza mia espressa autorizzazione.

## 4. Come scegliere la skill

Non occorre richiamarle tutte ogni volta. Per un'opposizione a decreto ingiuntivo, ad esempio, chiedi la skill di redazione atti civili e quella di controllo qualità; se il fascicolo è voluminoso aggiungi analisi fascicoli; se servono precedenti aggiungi ricerca giurisprudenziale.

## 5. Come lavorare con i documenti

1. Allega i PDF, Word o gli altri documenti del fascicolo nella chat.
2. Chiedi prima l'analisi del fascicolo e la ricostruzione cronologica quando i documenti sono numerosi.
3. Fai redigere l'atto dopo aver verificato la ricostruzione dei fatti.
4. Chiedi un controllo finale separato su rito, competenza, termini, preclusioni, conclusioni, documenti e citazioni.
5. Verifica personalmente la versione definitiva prima di usarla.

## 6. Riservatezza

Il repository principale è pubblico. Non inserirvi fascicoli, atti non anonimizzati, dati di clienti, codici fiscali, indirizzi, documenti sanitari o informazioni coperte dal segreto professionale. I documenti di causa vanno trattati nella conversazione o in uno spazio privato autorizzato, non nel repository pubblico.

## 7. Limite importante

Il collegamento GitHub permette a ChatGPT di consultare i file quando gli strumenti GitHub sono disponibili nella conversazione. Non garantisce che ogni nuova chat li richiami automaticamente. Per questo è consigliato usare il prompt qui sopra all'inizio di un incarico, oppure chiedere esplicitamente di consultare la skill pertinente.
