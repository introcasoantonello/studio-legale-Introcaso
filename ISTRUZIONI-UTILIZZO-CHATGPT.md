# Come utilizzare le skill dello Studio Legale Introcaso con ChatGPT

## 1. Cosa sono

Le skill sono istruzioni operative specializzate, conservate in questo repository. Non sono programmi autonomi e GitHub non le installa automaticamente in ChatGPT. Servono a far applicare un metodo stabile alle attività dello Studio.

## 2. Il modo più semplice: richiamarle in chat

Con GitHub collegato a ChatGPT, apri una nuova conversazione e scrivi:

> Per questa attività consulta nel repository introcasoantonello/studio-legale-Introcaso la skill skills/assistente-giuridico-italiano/SKILL.md e le skill specialistiche pertinenti. Leggi i file prima di iniziare e applicane le istruzioni. Se non puoi accedere al repository, dimmelo senza fingere di averlo consultato.

Poi descrivi il lavoro e allega i documenti necessari.

## 4. Ricerca web con Firecrawl

Se Firecrawl risulta collegato a ChatGPT, il modulo di assistenza può utilizzarlo per cercare pagine pubbliche e acquisirne il contenuto. Verificare sempre la fonte originaria e privilegiare Normattiva, Gazzetta Ufficiale e portali istituzionali. Firecrawl non è una banca dati giuridica ufficiale e non implica accesso a Italgiure, DeJure o altri archivi riservati. Non inviare a servizi esterni fascicoli o documenti contenenti dati riservati o non anonimizzati.

## 5. Prompt pronto da copiare

> Lavora come assistente giuridico dello Studio Legale Introcaso. Prima di iniziare, consulta nel repository GitHub introcasoantonello/studio-legale-Introcaso la skill skills/assistente-giuridico-italiano/SKILL.md e tutte le skill specialistiche pertinenti. Leggi i file e applicane il metodo. Usa la ricerca web/Firecrawl solo se il connettore è effettivamente disponibile; privilegia fonti primarie istituzionali e verifica sempre la pagina originaria. Non dichiarare accesso a Italgiure, DeJure o altre banche dati se non vi hai realmente avuto accesso. Seleziona anche il modello dello Studio eventualmente allegato o disponibile, senza modificarne arbitrariamente struttura e formulazioni. Distingui fatti documentati, allegazioni, inferenze e questioni da verificare. Non inventare norme, sentenze, massime, date, importi o dati processuali. Per ogni precedente indica gli estremi e verifica esistenza e pertinenza; se non puoi verificarlo, dichiaralo. Redigi in italiano giuridico, con stile discorsivo e professionale, rispettando le mie indicazioni di formattazione. Prima di consegnare, esegui il controllo qualità fattuale, normativo, processuale e redazionale. Non effettuare depositi, notifiche o invii senza mia espressa autorizzazione.

## 6. Come scegliere le skill

Non occorre richiamarle tutte ogni volta. Per un'opposizione a decreto ingiuntivo, ad esempio, usa assistente giuridico italiano, redazione atti civili e controllo qualità; se il fascicolo è voluminoso aggiungi analisi fascicoli; se servono precedenti aggiungi ricerca giurisprudenziale.

## 7. Come lavorare con i documenti

1. Allega i PDF, Word o gli altri documenti del fascicolo nella chat.
2. Chiedi prima l'analisi del fascicolo e la ricostruzione cronologica quando i documenti sono numerosi.
3. Fai redigere l'atto dopo aver verificato la ricostruzione dei fatti.
4. Chiedi un controllo finale separato su rito, competenza, termini, preclusioni, conclusioni, documenti e citazioni.
5. Verifica personalmente la versione definitiva prima di usarla.

## 8. Riservatezza

Il repository principale è pubblico. Non inserirvi fascicoli, atti non anonimizzati, dati di clienti, codici fiscali, indirizzi, documenti sanitari o informazioni coperte dal segreto professionale. Non inviare documenti riservati a servizi esterni di ricerca. I documenti di causa vanno trattati nella conversazione o in uno spazio privato autorizzato, non nel repository pubblico.

## 9. Limite importante

Il collegamento GitHub permette a ChatGPT di consultare i file quando gli strumenti GitHub sono disponibili nella conversazione. Non garantisce che ogni nuova chat li richiami automaticamente. Per questo è consigliato usare il prompt qui sopra all'inizio di un incarico, oppure chiedere esplicitamente di consultare la skill pertinente.
