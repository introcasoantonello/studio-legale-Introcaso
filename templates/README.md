# Modelli dello Studio

Inserire qui i modelli approvati dallo Studio, mantenendo una copia originale non modificata.

Per ogni modello indicare:
- nome dell'atto e rito;
- autorità giudiziaria di riferimento, se specifica;
- data/versione del modello;
- campi variabili da compilare;
- eventuali istruzioni di formattazione.

Non inserire dati reali di clienti in modelli destinati al riuso.
